# Fonts

`Virgil.ttf` and `Virgil.woff2` are the Virgil hand-drawn font from Excalidraw (https://github.com/excalidraw/virgil). It is
licensed under the SIL Open Font License 1.1 (OFL-1.1), not under this repository's license. `../sketch.py` draws diagram
text as glyph outlines from `Virgil.ttf`, so the generated SVGs do not need the font installed.
